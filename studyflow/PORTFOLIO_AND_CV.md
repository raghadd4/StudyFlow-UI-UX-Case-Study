# Portfolio description

**StudyFlow — Study smarter. Stress less.**

StudyFlow is a responsive student productivity app that brings courses, assignments, deadlines, and study sessions into one focused place, designed around a single question: *what should I focus on right now?* I designed a full token-based design system (color, type, spacing, and a shared component library) and built it as a real, working React application — adding, completing, and deleting tasks, running a Pomodoro-style focus timer, and tracking weekly study progress all persist to local storage. The project includes a complete UI/UX case study covering the persona, user flows, wireframe-to-final comparisons, and accessibility decisions.

# CV bullet points

- Designed and built **StudyFlow**, a responsive student-productivity web app (React, Tailwind CSS) featuring a custom design system, 10 fully interactive screens, and local-storage persistence, taking the project from concept and user flows through a working, deployable prototype.
- Created a reusable component library (buttons, cards, progress indicators, modals, forms) driven by a shared color, type, and spacing token system, keeping 10+ screens visually and behaviorally consistent.
- Designed and implemented a Pomodoro-style focus-session flow with live timer state, and an analytics view (Recharts) surfacing weekly study time, task-completion rate, and study streaks — all computed dynamically from underlying task and session data.
